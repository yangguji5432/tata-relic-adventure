塔塔冒险队活动助手 · 遗迹 / 围猎 / 钓鱼

【围猎推荐半自动使用，请先阅读】
目前萨满出现提示相对可用，但死亡、位置与退出判断误判较多。建议用户在旁观察，不推荐无人看管自动刷。
方案一（推荐，只听提示）：勾选“仅观察：持续测试萨满出现与死亡线索”和“萨满出现时声音提醒”，启动后手动进入200倍场。锁定、判断死亡及退出均由用户完成。普通“仅观察，不点击”只读一次，不能代替持续观察。
方案二（自动放锁定并提醒）：取消两种观察模式，开启声音提醒，程序按现有流程尝试自动锁定，用户在旁判断萨满死亡并及时手动退出。现有自动退出、超时和下一轮规则仍生效；本次没有增加“只放锁定、关闭全部退出判断”的模式。可取消自动下一轮避免自动重进。
特别提示：萨满可能在入场前或屏幕外被秒杀，程序随后仍可能释放锁定，转打小怪，而且不保证及时暂停或退出，可能持续浪费金币。请及时手动退出场地。
F9/停止只停止助手继续操作，不能停止游戏自身已经开启的自动攻击；仍需手动退出场地。
本次不修改游戏操作及自动判断逻辑，只调整描述与声音提醒。

【启动与迁移】
安装 Python 3.10+（含 tkinter）及简体中文Windows OCR，准备已经安装的MuMu和adb.exe。
在本目录终端运行：python -m pip install -r requirements.txt
然后双击“启动活动助手.bat”，或运行 python app.py。
本包不含免安装exe或私人图鉴。旧助手保留，不要同时用两个助手操作同一实例。
遗迹图鉴可在“遗迹探险”页点击“导入图鉴”，选择旧版data/catalog.json，核对后保存。
本合并版的data与旧版分开，首次20件分数为0。设备请重新绑定、预览并核对校准。

【共用设置】
先刷新设备、选择实例、绑定当前游戏，再查看后台画面。
如果包含黑边或安卓导航栏，先校准游戏区域。区域变化会清空点击和围猎识别区域的校准。
保留原有MuMu多画面动态匹配：物理ID截图、逻辑编号点击，目标不明确则停止。
两项活动同一时间只允许运行一个任务。切换标签不自动停止已有任务，需要按停止或F9。

【遗迹探险】
操作和图鉴扫描方式与旧助手一致，详见“使用说明.txt”。
普通撤离≤20%、保护撤离≤60%，可以修改。
保护只由明确更高分图鉴更新成功触发；未读清、未知画面、中途接管不会触发。
未知画面前20秒按至少1秒尝试，之后按至少5秒尝试，总计60秒仍未知暂停。

【围猎萨满：首次设置】
1. 手动进入围猎活动，选择200倍场。只有200倍场才允许开始；程序不自动切换倍率。
2. 选择“围猎萨满（试用）”标签。默认“仅观察，不点击”，狂暴默认关闭。
3. 校准点击位置：下拉框分别选择“围猎：开始”“围猎：锁定”“围猎：狂暴”“围猎：退出”，在对应截图中点按钮中心，再保存。校准的单击只记录，不操作游戏。
4. 必要时点击“校准识别区域”：主页框“200倍场”；场内框顶部“200倍场”、个人黄色分数及锁定图标右下角x数量。分数区域只包含数字及单位，不要包括动画。数量区域只框x和数字，不要包含“锁定”文字。
5. 先在主页观察，再手动进入场内观察。日志应分别读出200倍场；场内应读对锁定数量。倍率和数量采用多尺寸等比例文字读取，至少两次一致才认可。倍率框偏移时会尝试UI范围及徽标定位；徽标相似不能单独放行。数量支持忽略x7前的图标碎片，并尝试跟随锁定图标定位。
6. 检查正确后停止，取消“仅观察”，再启动。可选“锁定后开启狂暴”，每轮最多一次。

【仅观察：持续测试出现与死亡线索】
在“围猎萨满（试用）”页勾选“仅观察：持续测试萨满出现与死亡线索”，再点击启动。
此选项优先于自动模式：即使未勾选普通“仅观察”，也不入场、不释放技能、不点击退出。
请手动进入场内；程序持续读取截图，在状态栏和运行记录报告萨满出现、所在象限、头像和锁定标志状态，以及个人分数字形是否可读。道具不足3个也可以测试。
可手动释放锁定或只看其他玩家击杀，观察识别结果；程序不会替你结束游戏自身的攻击。
个人分数字形连续两帧变化，报告“疑似萨满死亡”；头像消失后2秒内锁定跨象限/瞬移，报告“疑似目标死亡或锁定转移”。这些线索不能单独证明一定击杀萨满。
头像消失但没有锁定标志或得分变化，报告“无法确认死亡”，继续观察；不将未开锁定时没有标志当作死亡。其他象限有新萨满头像并连续确认两帧时，记录上一只生死未确认并切换跟踪，不会一直卡在上一象限。
画面未知时继续观察并报告无法判断；安卓绑定目标检查仍生效。按停止/F9结束测试，已手动开锁定时请自己退出场地停止消耗。
取消此持续测试选项后，原来的“仅观察，不点击”仍为单次读数模式。

【锁定不足自动暂停：独立开关】
“锁定不足3个自动暂停（关闭时跳过数量检查）”默认开启；取消勾选可关闭此数量限制。
开启时：等待期间不足3个则退出暂停；本次使用后从3降到2则完成本次目标、离场后暂停。
关闭时：即使数量为0、1、2也不因低数量暂停，仍会按头像尝试释放锁定；是否继续入场由自动下一轮开关决定。
开启此项时，数量读不清仍退出暂停；关闭此项后自动运行不再读取数量，日志显示“未读取（已关闭数量检查）”，不把未知数量伪造为0。倍率不是200倍、攻击超时、无法确认退出等处理不变。零数量不保证锁定技能能够成功释放。此开关启动时保存。
下文所有“数量不足3个暂停”均指开启本开关时。

【自动下一轮与声音提醒】
“自动进行下一轮”默认开启。正常结束本次目标、退出并确认回到主页后，重新核对200倍场再入场。关闭时只完成本轮，确认离场后暂停。
开启数量暂停时锁定不足3个会暂停；攻击超时、无法确认退出等情况仍暂停。画面连续未知触发退出后，如果已确认回到主页且开启自动下一轮，会重新核对200倍场再继续；关闭自动下一轮则暂停。
“萨满出现时声音提醒”默认关闭。开启后，首帧匹配到头像时播放一次80毫秒的Windows直接短哔声；支持普通观察、持续观察和自动运行。提示框短暂闪烁不会反复响，新头像再次匹配会再次提醒。
点击“试听警报”可检查Windows音量和提示音；声音直接启动短音线程播放，不经过界面消息排队，不等待播完再操作游戏；自动锁定仍需原有连续确认。声音延迟仍包含ADB截图和识别耗时。启动时保存这两个开关的选择。
持续观察模式全程不点击，自动下一轮开关在此模式下不会自动入场。

【围猎流程】
确认200倍主页→开始围猎→核对场内200倍和锁定数量→不攻击地等待。
数量少于3个，直接退出，确认回到主页后暂停并弹窗提醒“去1倍场打道具”。
检测四角中的唯一萨满头像，支持多尺寸和跨分界线的头像。连续确认且个人分数底图稳定后，点击一次锁定。日志/状态先显示已发现的象限；如果提示个人分数未确认，需要核对分数区域。一般不需要按住攻击。
锁定后数量按本次使用扣减。使用后从3降至2，不中断这次攻击；本次判断结束、退出后再暂停，不能再进入下一局。

【围猎退出条件】
个人黄色分数字形连续两帧稳定变化，退出。
头像消失后的2秒内：锁定标志连续出现在其他象限，或者已追踪标志明显瞬移，退出。
头像消失满2秒仍未确认锁定标志，或者确认过但标志已丢失，退出。可见的标志正常缓慢入场不当作瞬移。
正常离场后自动重新确认200倍场，再进入等待下一只。
攻击超过页面设定的上限（默认15秒，可设3—120秒），退出并暂停，防止识别失效后无限消耗。
自动运行时，场面连续5秒无法确认会先点击围猎退出；确认回到主页后，开启自动下一轮则重新核对200倍场继续，关闭则暂停。道具不足3个仍暂停。退出后5秒仍未确认主页会重试一次，再过5秒仍未确认则暂停并提醒手动退出。仅观察模式不发送退出点击。不会套用遗迹的未知画面补点策略。
如退出后迟迟未回主页，会重试一次退出，仍未离开则暂停。

【停止】
F9或停止按钮只停止助手发出新操作。游戏已释放锁定后会自己持续攻击，手动停止助手时，请同时手动点游戏底部退出停止攻击。
正常自动结束会先点击退出并确认主页，再决定是否继续或提示补道具。

【当前限制与验证】
围猎为新活动试用实现，尚未实机验证完整一轮；请在旁看第一轮，不要无人值守。
头像与标志用局部图像匹配，个人分数用黄色字形两帧变化；不是可靠的数字增加OCR证明，特效遮挡或UI变化仍可能误判。蓝/金色击杀数字、屏幕边缘只露出300暂不独立判断。
入场文字识别会耗时；战斗中不进行慢速全文OCR。快速图像检测在当前电脑样本约0.2秒，不含ADB截图和检查。其他电脑的实际间隔可能更长，2秒判断不是硬实时保证。
离线检查包括：主页与场内区分、200倍OCR、x2及x7数量OCR、旧校准框偏移回退、头像/标志插入测试，以及原有遗迹和新增围猎流程测试。没有读取或消耗实际游戏道具。

【识别速度】
图像匹配改为缩小定位、原尺寸彩色复核并缓存模板。日志每10秒报告包含ADB截图的实际平均耗时，便于排查模拟器或ADB速度；不承诺固定每秒帧数。点击前的ADB绑定游戏与显示路由检查保留。

【重复识别失败】
场内识别使用不含数量的锁定图案，结合退出按钮或个人分数字形。首次未知会在日志输出各图案的匹配分数。
独立开关“2分钟内3次未知退出后暂停”默认关闭：关闭时，只要确认离场且开启自动下一轮，就继续重新核对200倍场入场，不因累计未知次数暂停。开启时，2分钟内第三次未知退出会在确认离场后暂停。该选项启动时保存，独立于锁定不足暂停开关。无法确认离场、倍率不正确等其他停止条件仍生效。此开关不修复画面位置识别本身，仍需核对“查看后台画面”和游戏区域。

【自选提示音】
围猎页“选择提示音文件”支持WAV、MP3、WMA等本机音频；“试听警报”立即试听，“恢复默认声音”回到短哔声。选择结果自动保存在本机设置，不随分享包分发你的音频。原文件移动或删除后请重新选择。
优先使用无起始静音的短PCM WAV；其他格式依赖Windows媒体组件，播放失败请查看日志并换WAV。自选音频不会加速ADB截图和头像识别。

【第三项活动：钓鱼助手 · ADB后台版】
参考并复用 https://github.com/zz11-m/tt_fish 的识别及相位预测源码，原作者zz11-m and contributors，GPL-3.0-only；许可证、原说明和改动记录在 third_party/tt_fish。
使用上方ADB选择设备、绑定当前游戏并预览完整游戏区域。钓鱼页不再选择Windows窗口、不要求空格映射，也无需保持模拟器Windows前台。
校准点击位置，选择“钓鱼：下钩/拉钩/黄条/收下”，框选各阶段共用操作点。默认位置约游戏区域水平50%、垂直86.5%，请自行核对。
默认持续仅观察。启动后检查识别阶段，确认后停止并取消仅观察启动。F9停止，三个活动互斥。
不停钓开启时忽略次数/时间上限；关闭时上限生效。黄条自动判定复用tt_fish相位预测，输入前重新校验当前时机。可以关闭自动黄条，由用户手动处理。
输入延迟补偿0—250毫秒，默认150；实际ADB和模拟器延迟会影响黄条命中率，后台版尚未完整实机验证，不保证高频或准确命中。过期触摸跳过，不按旧计划补点。
模拟器Windows窗口可切换/最小化（仍需模拟器正常渲染），安卓内部仍必须游戏前台；目标包名或画面路由改变会暂停。
内层tt_fish说明为保留的原前台版文档；本整合版使用此ADB说明，无F8开始要求、不使用Windows空格。
